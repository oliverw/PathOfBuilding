# Path of Building Community

Offline build planner for Path of Exile. Players design character builds with passive trees, skills, items, and see calculated DPS/defense stats. Desktop app (Windows exe via SimpleGraphic engine) written primarily in Lua.

## Tech Stack

- **Language**: Lua 5.1 (LuaJIT)
- **Runtime**: SimpleGraphic (custom C++ 2D engine) — [runtime/](runtime/)
- **Testing**: Busted 2.2.0 + LuaCov — [spec/](spec/)
- **CI**: GitHub Actions — [.github/workflows/](.github/workflows/)
- **Data pipeline**: Python 3.7+ scripts for manifest/export generation

## Build & Test Commands

```bash
# Run tests (requires Docker)
docker-compose up

# Run tests directly (requires luajit + busted installed)
busted --lua=luajit

# Regenerate ModCache (required after mod parsing changes)
cd src && REGENERATE_MOD_CACHE=1 luajit HeadlessWrapper.lua

# Update file manifest hashes
python3 update_manifest.py --in-place

# Run the application (Windows or Wine)
./runtime/Path\ of\ Building.exe
```

## Development Notes

### Dev Mode (automatic when running from repo)
- **F5**: restart in-place
- **Ctrl+~**: toggle console (`ConPrintf()` to output)
- **Ctrl+F5**: regenerate ModCache
- **Alt**: show debug info on tooltips (unrecognized mods, node IDs, node power)

### PR requirements
- All PRs target `dev` branch (staging before `master`)
- If mod parsing changed: regenerate and commit [src/Data/ModCache.lua](src/Data/ModCache.lua)
- Auto-generated data files (header: `-- This file is automatically generated`) — change the export scripts in [src/Export/](src/Export/) instead
- Tests must pass; CI also validates ModCache hasn't changed unexpectedly

### Auto-generated files — do NOT edit directly
- [src/Data/ModCache.lua](src/Data/ModCache.lua) — regenerate via Ctrl+F5 or env var
- [src/Data/ModItem.lua](src/Data/ModItem.lua), [src/Data/Gems.lua](src/Data/Gems.lua), and other Data/ files with the auto-generated header — regenerate via Export scripts
- [src/TreeData/](src/TreeData/) — generated from GGG game data
